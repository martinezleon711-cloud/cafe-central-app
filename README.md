# café-central-app.

Nombre del proyecto: aplicación café-central.

Descripción: aplicación para gestionar las operaciones y servicios de una cafetería cetral .

Problema que se resuelve: optimización y control de pedidos, la administración de productos.

Funcionalidades principales: * registro y control del menú y productos. * gestión de pedidos de los clientes. * seguimiento de ventanas y cortes de caja.
